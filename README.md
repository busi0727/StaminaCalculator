# 별⭐찌 마을 스태미나 효율 계산기

스태미나 물약 조합을 기반으로 **최적의 효율과 수익을 계산**할 수 있는 웹 기반 계산기입니다.  
사용자가 입력한 시세를 기준으로 가장 효율적인 조합을 자동으로 분석합니다.

---

##  Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

(외부 라이브러리 없이 구현)

---

## Notes

- 시세는 사용자가 직접 입력해야 합니다
- 입력값에 따라 결과가 달라집니다
- 최대 물약 개수: **5개**
